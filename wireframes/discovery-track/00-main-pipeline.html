States to consider

  • Empty — no audio uploaded yet → only Stage 1 unlocked; CTA "Upload audio to start"
  • Loading — STT running / LLM generating → stage card shows spinner + estimated time
  • Error — STT failure / LLM rate-limit → inline error with retry; doesn't break pipeline state
  • First-run mode — no project context → wizard prompt: "Start a new Discovery from audio?"
  • Resumed session — user returns mid-pipeline → highlight Stage N (active), scroll into view
  • Branched flow — user jumps to existing BA module without completing Discovery → confirm dialog ("Discovery is incomplete; some context will be missing")
  • Concurrency — two team members editing same Approach Note → optimistic-lock check; latest version wins
  • Phase-2 mode — disabled affordances become enabled; "Generate Budget" / "Share with Client" exposed

Open questions for your review

  1. STT provider for Phase 1 — local Whisper (free, needs ffmpeg + ~1GB model) or cloud STT (OpenAI/AWS, requires API key, no local deps)? Default: local Whisper, abstracted via STTProvider port so cloud swap is one env var.
  2. Discovery scope — is Discovery created at project level (one Discovery per project) or module level (one Discovery per module)? Default: project level — a project has one set of BRD/Approach Note that fans out to multiple modules.
  3. EPIC multi-source UI — should the context-ref picker (BRD/AN/Lo-fi/Hi-fi/FRD/PRD) be Phase 1 or Phase 2 of this initiative? Default: Phase 2 — Phase 1 = AN-only or FRD-only.
  4. Hi-fi mockup rendering — sandboxed iframe with same-origin off, or static .png snapshots? Default: sandboxed iframe — preserves callout interactivity.
  5. Audio storage — keep raw audio after WFT generated, or purge for privacy? Default: keep with retention policy (90d) per project setting.
  6. Existing PRD module integration — wire as Stage 8 of Discovery pipeline, or keep PRD as a separate top-level workspace (current behaviour)? Default: link from pipeline but reuse existing PRD route — no UI duplication.
  7. Versioning of BRD — append-only like Approach Note, or overwrite? Default: overwrite (BRDs go through review then sign-off — versioning would be cosmetic).
  8. Pipeline gating — strict (Stage N+1 locked until Stage N quality criteria pass) or advisory (warn but allow)? Default: advisory — power users can run stages out of order.
