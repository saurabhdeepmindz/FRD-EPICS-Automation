States to consider

  • Empty — no WFT yet → shows "Complete Stage 1 first" with link back
  • Not generated — WFT present, no BRD → "Generate BRD" CTA prominent, sections list shows all empty
  • Generating — LLM running → progress bar, sections fill in sequentially
  • Generated, all green — every quality check passes → Continue CTA enabled, no warnings
  • Generated, with warnings — some quality checks fail (e.g. FR-5 not testable) → warn-state badge on §6, but Continue still enabled (advisory gating)
  • Editing — user editing a section → unsaved-changes indicator, autosave or explicit save
  • Regenerating — user clicked regenerate → confirmation dialog ("This will overwrite the current BRD"); Phase 2 will skip dialog and create new version
