States to consider

  • Empty — AN locked but no wireframes yet → catalogue picker prominent, gallery empty, "Generate selected" CTA
  • Generating — LLM running per-screen → progress bar, gallery fills sequentially with ⟳ indicators
  • All green — coverage validation passes → Continue enabled, no warnings
  • With warnings — orphan FR or orphan screen → red banner with specific issue, jump-to-fix link, Continue still allowed (advisory)
  • Branding changed in AN — banner: "Branding tokens have changed in AN v4 since this set was generated · Re-render with new branding"
  • Per-screen editing — clicking a tile opens the per-screen editor (separate wireframe — to be detailed later)
  • Custom screen added — user adds a non-catalogue screen; matrix updates; quality check warns if it has 0 FR mappings
