What is intentionally NOT changed (existing flow preserved)

  • SkillStepper — 8 steps, same labels, same behaviour, same BaModuleStatus state machine
  • FRD generation service — same prompt, same output (Discovery context optional)
  • User Stories / Sub Tasks / LLD / FTC services — zero modifications
  • Module creation flow — still works without a Discovery (modules can be created standalone; Discovery context is optional)
  • Module page layout — only one structural addition (the banner above the stepper); everything else preserved
  • Existing screen upload + analysis flow — untouched

States to consider

  • No Discovery for project — module created without AN → banner shows: "No Approach Note linked. Run Discovery or Continue without context" (advisory)
  • Stale AN version — module linked to AN v3, but project AN is now v5 → banner shows: "AN has new versions (v4, v5). Update link"
  • Phase-2 multi-source enabled — picker buttons become active; user can layer BRD / Lo-fi / Hi-fi / FRD / PRD context on top
  • Module created from scratch (legacy flow) — banner shows minimally: just an "Add Approach Note context" CTA to opt in
  • EPIC regenerated with different context — EPIC artifact shows version chips: "Generated with AN v3" → "Regenerated with AN v5" (audit trail)
