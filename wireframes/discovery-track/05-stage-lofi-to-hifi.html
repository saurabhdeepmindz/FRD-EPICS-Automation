States to consider

  • Empty — lo-fi locked but hi-fi not yet generated → "Generate hi-fi from lo-fi" CTA prominent
  • Generating — LLM running per-screen → progress bar, gallery fills sequentially
  • Parity check passes — Continue CTA enabled
  • Parity check fails — red banner: "Screen 04 has callout 5 in hi-fi but not in lo-fi" → must fix before Continue
  • State variant view — user toggles to "Loading" → all gallery iframes swap to skeleton state
  • Annotations drawer open — overlay shows callout list; clicking a callout scrolls iframe to that element
  • Lo-fi changed — banner: "Lo-fi has been edited since hi-fi was generated · Re-render hi-fi to keep in sync"
  • Print mode — @media print hides drawer, state toggles, pager — clean PDF export per skill 05 §6
